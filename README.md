# microclog_boat

Here is the boat system that we make in project.

## Repository Structure

- [`circuit design/`](circuit%20design/): Circuit schematics, pinout guides, and hardware documentation.
- [`esp code/`](esp%20code/): Arduino / C++ firmware for the ESP microcontroller (motors, sensors, actuators).
- [`rasp pi code/`](rasp%20pi%20code/): Python controller scripts, web interface, logging, and communications.
