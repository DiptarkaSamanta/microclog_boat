# Circuit Design & Hardware Schematics

This directory contains circuit diagrams, pinout guides, schematic files, and hardware design specifications for the microclog boat system.

## Components & Wiring
- **ESP Controller**: Pinouts for motor drivers (L298N / N20 / ESC), servo control (rudder), and sensors (IMU / Ultrasonic / GPS).
- **Raspberry Pi**: Power management, Serial/UART/USB connection to ESP, camera module wiring.
